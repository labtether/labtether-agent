# Security Policy

This policy covers the LabTether Go agent: the binaries and container image
published from this repository.

## Supported versions

| Version | Status |
|---|---|
| Latest release | Security fixes |
| `main` | Fixed first; not a release |
| Older releases | Upgrade to the latest release |

## Reporting a vulnerability

Please report suspected vulnerabilities privately. Do not open a public issue.

- Use GitHub private vulnerability reporting:
  [report a vulnerability](https://github.com/labtether/labtether-agent/security/advisories/new).
- Or email [support@labtether.com](mailto:support@labtether.com).

Include the affected version or commit, the platform, the impact, and steps to
reproduce. Redact tokens, passwords and other secrets from logs.

We aim to acknowledge reports within 5 business days. We prefer coordinated
disclosure: please keep details private until a fix or mitigation is
available, or until we agree on a timeline.
